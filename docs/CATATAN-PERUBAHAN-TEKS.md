# Catatan perubahan teks

Perubahan berikut dilakukan pada butir dari dokumen daftar tilik asli (salah ketik, ejaan, atau kalimat tidak lengkap). Isi dan jumlah butir tidak berubah. Hal-hal lain di luar teks butir:

- Pembagi skor dihitung otomatis: jumlah butir × jumlah penilai (2). KD II Point 1 (22, bukan 44), KD V Point 2 (14, bukan 12), KD V Point 3 (10, bukan 8), KD IV Point 4 (10 dengan 2 penilai), KD IV Point 5 (12 dengan 2 penilai).
- KD II Point 3: kolom pengamat berjudul nama posyandu diganti menjadi Penilai 1 dan Penilai 2.
- KD IV: file "Penyuluhan Germas" diperlakukan sebagai Point 2. Judul Point 1 dan 3 mengikuti isi dokumen, bukan nama file.
- Penomoran ganda pada KD V Point 2 dan Point 3 diurutkan ulang.
